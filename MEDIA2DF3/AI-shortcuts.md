<h1 style="color: darkred;">Adobe Illustrator Shortcuts</h1>

A quick reference guide to commonly used **Adobe Illustrator shortcuts** for the Composition Techniques, projects, and other course exercises.

## Drawing Shapes

| Action | Mac | Windows |
|---|---|---|
| Constrain shape proportions | **Shift + Drag** | **Shift + Drag** |
| Draw shape from centre | **Option + Drag** | **Alt + Drag** |
| Move shape while drawing | **Spacebar + Drag** | **Spacebar + Drag** |
| Add/remove polygon or star points | **Up / Down Arrow while drawing** | **Up / Down Arrow while drawing** |
| Duplicate while transforming | **Option + Drag** | **Alt + Drag** |
| Delete region with Shape Builder | **Option + Click** | **Alt + Click** |

> Hold **Shift** while drawing rectangles or ellipses to create perfect squares or circles.
