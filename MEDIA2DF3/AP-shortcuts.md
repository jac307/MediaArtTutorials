<h1 style="color: darkred;">Adobe Photoshop Shortcuts</h1>

A quick reference guide to commonly used **Adobe Photoshop shortcuts** for the Composition Techniques, projects, and other course exercises.

> These are the default Adobe Photoshop shortcuts. Shortcuts may differ if you have customized your keyboard settings.

## Basic Editing & Transformations

| Action | Mac | Windows |
|---|---|---|
| Undo | **Command + Z** | **Ctrl + Z** |
| Redo | **Shift + Command + Z** | **Shift + Ctrl + Z** |
| Cut | **Command + X** | **Ctrl + X** |
| Copy | **Command + C** | **Ctrl + C** |
| Paste | **Command + V** | **Ctrl + V** |
| Paste in Place | **Shift + Command + V** | **Shift + Ctrl + V** |
| Free Transform | **Command + T** | **Ctrl + T** |
| Confirm Transformation | **Return** | **Enter** |
| Cancel Transformation | **Esc** | **Esc** |
| Constrain / control transformation proportions | **Shift while transforming** | **Shift while transforming** |
| Transform from reference point / centre | **Option while transforming** | **Alt while transforming** |

> Photoshop's transform behaviour can depend on the selected tool and current preferences. Always check the **Options bar** while transforming.
