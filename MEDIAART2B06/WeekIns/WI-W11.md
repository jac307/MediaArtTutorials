# Motion Graphics and Compositing

## Individual project

## Goal

Create two short Adobe After Effects projects that demonstrate foundational motion-graphics and compositing skills.

You will:

1. Complete a basic keyframe-animation exercise.
2. Select one exploration pathway and create an original short work using the chosen technique.

> Attendance, participation, and active engagement during class activities are part of the project rubric.

## Project overview

- **Project type:** Individual
- **Software:** Adobe After Effects
- **Part 1 media:** Three to five video clips and/or images
- **Part 2 duration:** Depends on the selected pathway

## Required folder structure

Create:

```text
Lastname_Firstname_AE
├── 00_ProjectFiles
├── 01_Media
└── 02_Exports
```

Use the folders as follows:

| Folder | Contents |
|---|---|
| `00_ProjectFiles` | After Effects project files and related Adobe project files |
| `01_Media` | All video, image, Illustrator, Photoshop, and other source files |
| `02_Exports` | Final MP4 exports |

## Activities

Complete the two parts in order.

## Project requirements

Create a **30-second keyframe animation** using:

- Three to five video clips and/or images
- Position keyframes
- Scale keyframes
- Opacity keyframes
- Two or three additional animated effect properties

The final sequence should demonstrate that you understand how values change over time in After Effects.

## Source media

You may use:

- Media from your own projects
- Original images or videos
- Appropriately licensed media from [Pexels Videos](https://www.pexels.com/videos/){:target="_blank"}

Place all source files inside:

```text
01_Media
```

Do not move or rename source files after importing them into After Effects.

## Create the project

Save the After Effects project as:

```text
Lastname_Firstname_AEIntro.aep
```

Place it inside:

```text
00_ProjectFiles
```

## Composition requirements

Create a composition using:

- **Duration:** 30 seconds
- **Resolution:** 1920 × 1080 pixels
- **Aspect ratio:** 16:9
- **Frame rate:** 24 or 30 fps
- **Background:** Appropriate to the project

Use three to five visual layers.

## Animate the required properties

Animate:

- **Position**
- **Scale**
- **Opacity**
- Two or three additional effect properties

Possible additional properties include:

- Rotation
- Blur
- Colour
- Distortion
- Mask path
- Effect intensity
- Text tracking
- Anchor point
- Layer style properties

Use the Graph Editor or Easy Ease when appropriate to refine the motion.

    <span class="section-description">
      Remove the background from a moving subject and use masking to add or reveal another visual element.

## Project requirements

Create a **15–20 second video** that uses both:

- Rotoscoping
- Masking

Use rotoscoping to isolate a person or moving subject from the original background.

Use masking to:

- Add a new element
- Reveal part of another layer
- Conceal part of the image
- Combine multiple visual spaces

The rotoscoped edge and mask movement should remain visually controlled throughout the clip.

    <span class="section-title">Pathway 2. Keyframing and Green-Screen Compositing</span>
    <span class="section-description">
      Record a subject against a green screen, remove the background, and animate the keyed subject over layered imagery.
    </span>
  </summary>

<div class="section-content" markdown="1">

## Project requirements

Record a **15–20 second subject performance** against a green screen.

Then:

- Remove the green background.
- Place the keyed subject over one or more background layers.
- Animate the subject, background, or effects using keyframes.
- Correct spill and edge problems.
- Match the subject to the new environment through scale, position, colour, and lighting adjustments.

<details class="tutorial-section">
  <summary>
    <span class="section-title">Pathway 5. Expressions and Generative Animation</span>
    <span class="section-description">
      Use expressions across multiple layers to create controlled random, procedural, looping, or glitch-based behaviour.
    </span>
  </summary>

<div class="section-content" markdown="1">

## Project requirements

Create a **20–30 second animation** using:

- Five to eight layers or objects
- Two to four expressions

Use expressions to create:

- Random movement
- Repetition
- Oscillation
- Looping
- Glitch behaviour
- Procedural variation
- Relationships between layer properties

Possible expressions include:

- `wiggle()`
- `loopOut()`
- `time`
- `random()`
- Property links
- Simple mathematical relationships

Document or comment on the expressions used so that you can explain their function.
