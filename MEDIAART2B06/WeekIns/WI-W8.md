Film all planned shots and record your production sound. Collect ambient audio and, if need it, subtle instrumental music (no lyrics). Follow your pre-production plan and keep your files clearly organized.

- All video must be shot on a DSLR camera.  
- Metadata will be reviewed to verify:
  - Camera model  
  - Manual mode  
  - Resolution  
  - Frame rate  
  - Codec  
- No phone footage.  
- No stock footage.

<h3>📁 <code style="color: navy;">00_ProjectFiles</code></h3>

- W7 PDF submission (final pre-production package)  
- Later to be included:
  - Premiere project file (.prproj)  
  - Audition project file (.sesx)  
  - Autosaves  

<h3>📁 <code style="color: navy;">01_RawFootage</code></h3>

- All DSLR video files  
- Organized into subfolders by date: `YYYY-MM-DD`  

Each video file must be renamed using this protocol:  
`ProjectName_Shot#_Take#`

- Project name can be tentative (one or two words only)  
- Shot number must match the storyboard  
- Take number indicates how many times that shot was recorded  

Example:  
`Echo_S03_T02.mov`

<h3>📁 <code style="color: navy;">02_Audio</code></h3>

- All recorded files (WAV)  
- Downloaded/sourced files (WAV preferred; MP3 accepted)  

Naming protocol:  
`ProjectName_AudioType_SimpleDescription_Take#`

- Audio type = `ProdAudio` (Production Sound), `Ambience`, or `Music`  

Example:  
`Echo_Ambient_LibraryHall_T01.wav`
