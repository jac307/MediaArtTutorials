# P1: Critical Research-Creation Profile

## Overview

**In pairs**, students will **research an artist or collective addressing issues of equity, diversity, and inclusion**. Drawing on course readings and artistic sources, groups will iteratively develop a multimodal profile for the course blog, presenting and revising it each week through research, feedback, and critical discussion.
